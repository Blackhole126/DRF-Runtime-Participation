# Known Limitations and Verification Boundary

## PROVEN

The local integration between the supplied SVACS runtime and supplied Capability Registry Foundation.

## VERIFICATION REQUIRED

- Remote or production canonical registry endpoint and credentials.
- Any registry beyond the supplied Capability Registry Foundation.
- Structured registry support for trace/provenance, authority boundary and compatibility fields.

## Explicit non-claims

- No parallel registry was created.
- No runtime registry was invented.
- No registry schema was extended.
- No sovereign or constitutional authority was created by integration.
- No production acceptance was claimed from a local proof.
